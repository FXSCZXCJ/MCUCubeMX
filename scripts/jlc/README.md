# 嘉立创 EDA Pro 对接（MCUCubeMX ↔ EDA）

MCUCubeMX 通过官方 WebSocket 桥与嘉立创 EDA Pro 专业版实时通信：

```text
MCUCubeMX (浏览器) ──HTTP /execute──▶ bridge-server.mjs (:49620-49629)
                                      ──WS /eda──▶ run-api-gateway 扩展 ──▶ EDA Pro
```

## 一次性准备

1. 在嘉立创 EDA Pro 中安装官方扩展 **Run API Gateway**：
   <https://jlc-ext.com/item/oshwhub/run-api-gateway>
   安装后在扩展管理器里勾选 **允许外部交互** 与 **显示在顶部菜单**。
2. 启动本地桥（本目录的 `bridge-server.mjs` 是官方实现，MIT-0 许可）：

   ```powershell
   npm run jlc:bridge
   ```

   桥会自动占用 `49620-49629` 中的第一个空闲端口，并等待 EDA 扩展握手。
   **开发模式下 `npm run dev` 会自动拉起本地桥**（Vite 插件），无需手动执行；
   也可以一条命令同时启动 Vite 和桥：

   ```powershell
   npm run dev:all
   ```

## 使用

1. 打开 EDA Pro，确保扩展已加载（顶部菜单出现 API Gateway）。
2. 打开 MCUCubeMX，点击顶栏 **嘉立创**。
3. 首次使用：**扫描连接** → 选择 EDA 窗口 → **读取当前工程** → **扫描原理图 MCU**，并选中要同步的 MCU。
4. 之后打开面板会自动恢复所选 MCU，直接点 **一键同步** 即可（可勾选“同步免确认”跳过变更对比对话框）。
5. 如果先在 EDA 原理图里用鼠标点选 MCU（如 U1），**扫描原理图 MCU** 会把它自动排到第一位并优先选中（列表中标有“EDA 已选中”）。
6. 选中 MCU（如 `GD32L233RCT6`）→ **读取引脚配置**。
7. 预览“引脚 → 网络”映射后点击 **导入到工程**：会先弹出**变更对比**对话框（新增/修改/不变/移除），确认后才写入。
8. 反向同步：点击 **同步到 EDA**，按引脚现有连接方式处理（已连端口→更新端口；线段→改线段网络；未连→新增 IN/OUT 端口），同样先弹**变更对比**对话框确认。

导入规则：

- 只有能匹配到器件库规范引脚名、且已连线的普通 IO 引脚会被导入（网络名作为标签，默认输入模式）。
- 电源脚、NRST/BOOT/SWD 特殊脚、未连线与无法匹配的引脚会跳过，不纳入代码生成。
- 器件不在支持列表（当前为 GD32L233RCT6 / GD32F427VE）时只能预览，不能导入。
- 导出到 EDA 按引脚现有连接方式分流：
  - 已连接**网络端口**（NetPort/电源/地符号）→ 电源/地符号尝试更新网络名；**NetPort 因 API 限制无法直接修改（modify 仅限元件），改名或方向调整（如工程为输出但端口是 IN）一律删除旧端口并按正确方向重放**；
  - **线段**连接（导线）→ **删除该引脚的原线段**，并在引脚处放置网络端口（不再改线段网络名）；
  - **未连接** → 新增网络端口（输入端 IN、输出端 OUT，网络名=标签），端口按 MCU 引脚方向摆放（旋转角与引脚一致；NetPort-OUT 符号内部自带 180° 翻转，会自动补 180° 保证标签朝外）；
  - 无标签、特殊引脚、EDA 中找不到的引脚自动跳过。
- 同步时还会把引脚配置**写入 MCU 元件本身**（`otherProperty`，属性形如 `PA5_MODE` / `PA5_LABEL` / `PA5_PULL` / `PA5_EXTI` / `PA5_OTYPE` / `PA5_SPEED` / `PA5_LEVEL`），在 EDA 属性面板可见；网络端口/线段只表达网络名，不塞引脚配置。已配置消失的旧 `PAx_*` 属性会自动清理。

## ⚠️ 同步到 EDA 警告

- **会真实修改你的原理图**：已连端口会被改名、线段网络会被重命名、未连接引脚会新增网络端口（IN/OUT），网络名均为标签文本。
- 同步前建议先在嘉立创 EDA 里**另存/备份工程**；放置后立即检查引脚与网络，必要时在 EDA 中 Ctrl+Z 撤销。
- **线段转端口会删除与该引脚连接点重合的线段**：如果一条线段横跨多个引脚，删除后相关引脚连接会断开，下次同步会各自补端口，请确认符合预期后再执行。
- 未连接引脚新增端口后会获得网络名（相当于给它命名），请确认这是你想要的行为。
- 输入/输出方向（IN/OUT）只影响标签外观，不改变原理图电气属性。

## 说明

- 网络名由“引脚坐标 ↔ 导线端点”几何匹配得到，不依赖 BETA 的网络类接口，实测可靠。
- 面板打开时自动扫描桥；桥中途掉线会在“读取工程”时自动重连一次，并给出明确提示。
- 关闭桥：结束 `bridge-server.mjs` 进程即可；扩展会自动重连/重试。
- 集成测试：`tests/jlcBridge.integration.test.ts` 在本地桥在线时自动运行，离线自动跳过。
